I present with Quarto a lot, so I built the tools I kept missing.

- **Ink**: pen, highlighter, shapes, text and sticky notes over slides, a magnifier, a multi-page whiteboard, separate annotation sessions per class, and export to HTML, PDF or PNG with the ink baked in. Built for tablets and styluses, fine with a mouse. `quarto add ofurkancoban/QuartoInkExtension`
- **Laser Pointer**: a high-precision pointer with drawing tools and speaker-notes sync.
- **Progress Indicator**: a lightweight progress bar for reveal.js.
